# Manuales — CRUD Inventario

## 1. Introducción

Esta carpeta contiene la documentación destinada a explicar el uso, funcionamiento, instalación y mantenimiento del sistema CRUD Inventario.

Los manuales serán desarrollados progresivamente durante la implementación del proyecto y se actualizarán conforme evolucionen las funcionalidades del sistema.

---

## 2. Documentos

### Manual de usuario

Archivo:

`manual-usuario.md`

Estará dirigido a las personas que utilizarán la aplicación.

Incluirá principalmente:

- Acceso al sistema.
- Registro de cuenta.
- Inicio de sesión.
- Uso del dashboard.
- Registro de productos.
- Consulta de productos.
- Búsqueda.
- Edición.
- Eliminación.
- Control de stock.
- Cierre de sesión.

---

### Manual técnico

Archivo:

`manual-tecnico.md`

Estará dirigido a desarrolladores o personas encargadas de mantener el proyecto.

Incluirá:

- Tecnologías utilizadas.
- Requisitos para ejecutar el proyecto.
- Estructura de carpetas.
- Funcionamiento de los archivos JavaScript.
- Modelo de datos.
- Uso de localStorage.
- Configuración de Git.
- Instalación local.
- Mantenimiento.
- Evolución futura.

---

## 3. Estado actual

**Estado:** estructura inicial.

Los manuales serán completados progresivamente durante la implementación y las pruebas del sistema.

No se documentarán como terminadas funcionalidades que todavía no hayan sido implementadas.
